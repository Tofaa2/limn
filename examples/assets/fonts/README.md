Fonts for the text example and the text shaping tests, from the Noto project
(https://github.com/notofonts), under the SIL Open Font License 1.1
(`OFL.txt`). Nothing in the library itself uses them.

Noto Serif Tibetan, Noto Sans Javanese and Noto Sans Mongolian were added
with those scripts, from the same project under the same license.
